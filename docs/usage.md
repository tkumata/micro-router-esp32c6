# 使用方法

## 1. マイクロルータの起動

1. XIAO ESP32C6 を USB HUB やモバイルバッテリなどに接続します
2. スマホなどの端末で「micro-router-esp32c6」 SSID に接続します
3. その際のパスワードは「esp32c6router」です (デフォルト)

## 2. Wi-Fi 認証情報の入力・保存

1. スマホなどの端末の設定から「micro-router-esp32c6」という AP に接続します
2. 接続すると、キャプティブポータル機能で「http://micro-router.local」へ自動的に遷移します
   このキャプティブポータル機能は、初回時のみです
3. 自宅の Wi-Fi AP の認証情報 (SSID とパスワード) を入力します
4. 「保存して再起動」ボタンをクリックします
5. 保存時には、認証情報は端末固有鍵で暗号化された状態で NVS に書き込まれます

### 2.1 旧バージョンからの移行

- 旧ファームウェアで保存した平文の Wi-Fi 認証情報は、新しいファームウェアの起動時に自動で暗号化形式へ移行されます。
- 利用者が追加の操作を行う必要はありません。
- 移行後は旧平文キーは削除されます。

## 3. 動作確認

1. 端末が「micro-router-esp32c6」 SSID に接続されていることを確認します
2. https://www.google.com にブラウザでアクセスします

## 4. AP パスワードの変更

セキュリティ向上のため、AP のパスワードをデフォルトから変更することを推奨します。

1. 「micro-router-esp32c6」に接続した状態で http://micro-router.local にアクセスします
2. Web UI の「AP パスワード変更」セクションを見つけます
3. 新しい AP パスワードを入力します (8〜64 文字)
4. 「AP パスワードを保存して再起動」ボタンをクリックします
5. デバイスが再起動するまで待ちます (約 5 秒)
6. 再起動後、新しいパスワードで「micro-router-esp32c6」に接続してください

**注意**: パスワードを忘れた場合は、デバイスの Flash メモリを消去してリセットする必要があります。

## 4.1 セキュリティ上の注意

- 認証情報の保存保護は改善されましたが、AP の初期パスワードは引き続き変更を推奨します。
- Web UI へのアクセス制御は別途必要です。暗号化保存だけでは、AP に接続した第三者による設定変更までは防げません。

## 5. DNS フィルタリング機能の使用

ドメインレベルでの広告ブロック機能を利用する方法です。

### 5.1 ブロックリストの準備

1. **フィルタリストの入手**

   推奨: [豆腐フィルタ](https://github.com/tofukko/filter)などの Adblock Plus 形式のリストをダウンロードします。

   ```bash
   curl -O https://raw.githubusercontent.com/tofukko/filter/master/Adblock_Plus_list.txt
   ```

2. **ドメインリストへの変換**

   付属の Python スクリプトを使用して、本機で読み込める形式 (`domain.txt`) に変換します。

   ```bash
   python3 tools/convert_adblock_to_domains.py Adblock_Plus_list.txt domain.txt
   ```

   生成された `domain.txt` は、1 行 1 ドメインのテキストファイルです。

### 5.2 ブロックリストのアップロード

1. ルータの Web UI (`http://micro-router.local` または `http://192.168.4.1`) にアクセスします。
2. トップページの「DNS フィルタリング設定」リンク、またはメニューから `/dns-filter` にアクセスします。
3. 「ブロックリスト管理」セクションで、「ファイルを選択」ボタンを押し、作成した `domain.txt` を選択します。
4. 「アップロード」ボタンを押します。
5. 数秒〜数十秒でアップロードと適用が完了し、完了画面が表示されます。

### 5.3 フィルタの有効化・無効化

1. DNS フィルタリング設定ページ (`/dns-filter`) にアクセスします。
2. 「DNS フィルタ設定」セクションで、「DNS フィルタを有効にする」のチェックボックスを操作します。
3. 「保存」ボタンを押すと、即座に設定が反映されます。

### 5.4 統計情報の確認

DNS フィルタリング設定ページでは、以下の統計情報を確認できます。

- **総クエリ数**: 処理した全 DNS リクエスト数
- **ブロック数**: ブロックリストにマッチして遮断した回数 (および割合)
- **許可数**: 正常に名前解決した回数 (および割合)
- **ブロックリスト登録数**: 現在メモリにロードされているドメイン数

### 5.5 動作確認

PC やスマートフォンから以下のコマンドを実行して動作を確認できます。

**ブロック対象ドメインの確認:**

```bash
nslookup ads.google.com
# 結果: Address: 0.0.0.0 となればブロック成功
```

**許可対象ドメインの確認:**

```bash
nslookup www.google.com
# 結果: 正しいグローバル IP アドレスが返れば正常
```
